=========================================
  FoodTrust Frontend - Quick Start
=========================================

1. INSTALLATION
   -------------
   cd frontend
   npm install

2. ENVIRONMENT SETUP
   ------------------
   Create .env file with:
   VITE_API_URL=http://localhost:8000

3. START DEVELOPMENT
   ------------------
   npm run dev
   
   App runs at: http://localhost:3000

4. BUILD FOR PRODUCTION
   ---------------------
   npm run build

=========================================
   AVAILABLE ROUTES
=========================================

/           - Home page with feature overview
/analyze    - Sentiment analysis tool
/recommend  - Restaurant recommendations
/reviews    - Browse all reviews
/add-store  - Add new store/restaurant

=========================================
   API INTEGRATION
=========================================

All API calls go through:
- utils/apiClient.js (Axios configuration)
- utils/api.js (Endpoint definitions)

Interceptors handle:
- Request tokens
- Error toasts
- Response transformation
